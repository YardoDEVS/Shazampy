Shazampy

A desktop lyrics companion for Linux that continuously identifies the song being heard or played by the computer, retrieves synchronized lyrics, follows the current position, and displays a responsive seven-line lyric view with a live frequency spectrum.

Author: Gerardo García Alfaro Python 3 CC BY-NC 4.0 Linux Source available ☕ Support development

Overview

Shazampy continuously captures audio from a selectable source, builds rolling audio windows, identifies the track and its timeline position, retrieves synchronized LRC lyrics from LRCLIB, and keeps the currently playing lyric centered in a seven-line display. Linux uses FFmpeg + PulseAudio/PipeWire + SongRec; Windows x64 uses PyAudioWPatch/WASAPI + ShazamIO.

It can listen to a physical microphone or to a PulseAudio/PipeWire monitor source, which makes it possible to follow music that is being played directly by the computer. Its synchronization logic groups Shazam matches into temporal clusters and tracks coherent branches so repeated choruses or repeated song sections are less likely to send the lyric clock to the wrong part of a song.

Installation

The repository includes one cross-platform installer. Open a terminal or command prompt in the folder where you want Shazampy installed and run:

python3 install_shazampy.py

On Windows, python install_shazampy.py is also valid. The installer detects the operating system automatically.

LinuxInstalls shazampy.py, SongRec, FFmpeg/PulseAudio-compatible tooling and the Noto font packages available in the distribution.
Windows x64Installs Shazampy_Win.py, PyAudioWPatch, ShazamIO and a private Noto font set beside the application. A run_shazampy.bat launcher is created.

Useful options:

python3 install_shazampy.py --help
python3 install_shazampy.py --yes
python3 install_shazampy.py --dest ~/Applications/Shazampy
python3 install_shazampy.py --force
python3 install_shazampy.py --dry-run
python3 install_shazampy.py --skip-packages
python3 install_shazampy.py --skip-fonts
Windows 7: use Python 3.8.10 x64. It was the last CPython release with an official Windows 7 installer. Windows 7 and Python 3.8 are end-of-life, so this compatibility profile is intended only for legacy machines.

Running Shazampy

Linux

./shazampy.py

Windows

Double-click run_shazampy.bat, or run:

python Shazampy_Win.py

The first recognition starts after the rolling audio buffer has collected enough audio. On Linux, direct computer audio normally uses a source ending in .monitor. On Windows, press F until a WASAPI LOOPBACK source for the desired speakers/headphones is selected.

Audio inputs

Press F to refresh and cycle through the sources exposed by pactl. Shazampy distinguishes physical inputs from output monitors and attempts to classify onboard PCI audio, USB audio, Bluetooth audio and HDMI/DisplayPort devices.

pactl list short sources

A typical direct-output monitor looks like:

alsa_output.pci-0000_00_0e.0.analog-stereo.monitor

A typical physical microphone/input looks like:

alsa_input.pci-0000_00_0e.0.analog-stereo

Synchronization model

Recognition services may return more than one plausible position when a song contains repeated sections. Shazampy therefore does not simply select the nearest or largest offset. It groups candidate positions into nearby clusters, scores the support of each cluster, tracks coherent movement over successive recognitions and can relocate the active timeline when a new remote branch is confirmed repeatedly.

This approach is designed for difficult cases such as songs whose introduction repeats material heard again near the end. Manual timing controls remain available for LRC files whose own timestamps differ slightly from the master recording used for recognition.

Multilingual and Unicode lyrics

Shazampy stores and processes lyrics as Unicode text and normalizes LRC lyric lines to NFC. The installer adds the Noto family so Tk can render a very broad range of modern writing systems, including Japanese, Korean, Chinese, Arabic, Hebrew, Indic scripts, Thai, Georgian, Armenian, Ethiopic and many others.

On Windows, the installer downloads Noto fonts beside Shazampy and the application registers them privately at startup, so administrator access is not required for the fonts. On Linux, the installer uses the distribution's Noto packages.

Unicode reality check: no single font stack can promise a glyph for every assigned or historical Unicode code point. Shazampy aims for broad modern-language coverage and falls back to the operating system's fonts when a dedicated Noto face is unavailable.

Frequency spectrum

The spectrum panel sits below the keyboard instructions and spans the available width. It uses 48 logarithmically spaced bars. Because Shazampy captures at 16 kHz, the theoretical Nyquist limit is 8 kHz; the analyzer intentionally stops slightly below that limit.

The visual groups cover sub/bass, low-mid, mid, high-mid and treble regions. The analyzer is a visualization of the selected audio input; it is independent of the Shazam recognition decision.

Configuration and generated files

Per-song timing adjustments and debugging data are stored under:

~/.config/shazampy/

Current debug builds may create debug-sync.log. Spotify position data obtained through playerctl is used only as an optional diagnostic reference and is not required to choose the synchronization branch.

Troubleshooting

No microphone appearsRun pactl list short sources. Verify that the sound card is using a duplex/input-capable profile.
No monitor source appears on LinuxVerify that a PulseAudio-compatible server such as PipeWire-Pulse is active and that the output sink exists.
No WASAPI LOOPBACK source appears on WindowsRun python -m pyaudiowpatch to inspect WASAPI devices, then restart Shazampy and press F to refresh the list.
SongRec is missingRun the installer again without --skip-packages, or install SongRec natively for your distribution.
Empty-square iconsInstall Noto Color Emoji. Shazampy also includes text fallbacks when a usable emoji font is unavailable.
Lyrics slightly early/lateUse W/S, arrow keys, or the ±1 second controls. Per-song corrections are saved.
Changed song manuallyPress Space to clear the capture window and restart recognition from scratch.

Si sigues encerrado en Windows...

Shazampy includes a dedicated Windows x64 build. Follow these steps:

  1. Windows 10 or 11 x64: install a 64-bit CPython version from 3.8 through 3.12 and make sure Python is available from the command prompt.
  2. Windows 7 x64: install Python 3.8.10 x64. Newer CPython versions do not officially support Windows 7. Windows 7 and Python 3.8 are end-of-life, so do not treat this as a secure modern desktop configuration.
  3. Download or clone the Shazampy repository.
  4. Open Command Prompt in the Shazampy folder and run python install_shazampy.py.
  5. The installer automatically detects Windows, installs the pinned Windows dependencies, downloads broad Noto font coverage, writes Shazampy_Win.py and creates run_shazampy.bat.
  6. Launch Shazampy by double-clicking run_shazampy.bat.
  7. Press F to cycle audio devices. To capture the sound currently playing through speakers or headphones, choose the corresponding WASAPI LOOPBACK device.
  8. If Windows asks for network permission, allow Python/Shazampy to access the network so recognition and synchronized-lyrics services can be reached.

The Windows build uses PyAudioWPatch for WASAPI capture and ShazamIO for song recognition instead of Linux's PipeWire/PulseAudio + SongRec path.
